## Project Description

Tic-Tac-Toe is a two-player game played on a 3×3 grid. Players take turns placing X and O in empty cells. The program checks for winning combinations across rows, columns and diagonals. The game ends when a player wins or the board is full, resulting in a draw.

## Features

- Menu-driven interface
- Two-player gameplay
- 3×3 board
- Input validation
- Prevention of occupied-cell selections
- Win detection
- Draw detection
- Scoreboard
- Replay option
